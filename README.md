# طرود — نظام إدارة الشحن والتوصيل

نظام إدارة شحن ولوجستيات متكامل مبني حول ستة أدوار وظيفية، بتغطية جغرافية تشمل القليوبية بالكامل وامتداد القاهرة حتى مدينة نصر (22 منطقة تغطية). قاعدة بيانات لحظية على Supabase بثمانية جداول مستقلة تتزامن بين جميع الأجهزة فورًا.

## الأدوار

| الدور | الصلاحيات |
|---|---|
| المالك | كل الشاشات، حذف الطلبات والمستخدمين، تعيين الأدوار |
| الموارد البشرية | إدارة الفريق + التقارير + التحصيل + البلاغات |
| مشرف العمليات | الطلبات، المخازن، المسارات، البلاغات، التقارير، إسناد المندوبين |
| أمين الفرز | طلبات مخازنه فقط: إنشاء طلبات وعرض كود التتبع للمندوب |
| محاسب COD | التحصيل النقدي، إنشاء التسويات واعتمادها، التقارير |
| المندوب | تطبيق ميداني مستقل: استلام بمسح الباركود، توصيل، بلاغات ومحادثة مع المشرف |

## التشغيل محليًا

```bash
npm install
npm run dev
```

## الإعدادات (ملف .env)

بيانات الاتصال بقاعدة البيانات تُقرأ من ملف `.env` في جذر المشروع — عدّلها هناك بسهولة دون لمس الكود:

```bash
cp .env.example .env
```

ثم املأ القيم (تجدها في لوحة Supabase: **Settings → API**):

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

> ملاحظة: ملف `.env` مستبعد من Git تلقائيًا لحماية بياناتك؛ ما يُرفع للمستودع هو `.env.example` فقط. بعد تعديل `.env` أعد تشغيل خادم التطوير (`npm run dev`) لتطبيق التغييرات.

## إعداد قاعدة البيانات

نفّذ محتوى [`public/schema.sql`](public/schema.sql) مرة واحدة من **SQL Editor** في لوحة Supabase — ينشئ الجداول الثمانية (`tarood_users`, `tarood_orders`, `tarood_hubs`, `tarood_routes`, `tarood_issues`, `tarood_settlements`, `tarood_seq`, `tarood_positions`) مع سياسات RLS والبث اللحظي وبذر البداية.

حساب البداية: `owner / 1234`
