# 📦 طرود - نظام إدارة الشحن والتوصيل

## 🎯 نظرة عامة
نظام متكامل لإدارة عمليات الشحن والتوصيل، مصمم خصيصاً لشركات التوصيل في مصر. يوفر النظام حلاً شاملاً يتتبع دورة حياة الشحنة من لحظة الإنشاء حتى التسليم، مع دعم كامل للتواصل بين الإدارة والمندوبين في الوقت الفعلي.

---

## ✨ الميزات الرئيسية

### 📊 لوحة التحكم
- خريطة تفاعلية مباشرة لمواقع المندوبين والطلبات
- إحصائيات لحظية (عدد الطلبات، قيد التوصيل، تم التسليم، فشل التسليم)
- رسوم بيانية لتوزيع حالات الطلبات
- متابعة المندوبين المتصلين

### 📦 إدارة الطلبات
- إنشاء طلبات شحن جديدة مع توليد أكواد تتبع تلقائية
- دعم مناطق التغطية (القليوبية والقاهرة)
- تتبع كامل لمراحل الشحنة (8 مراحل)
- دعم الدفع النقدي (COD) والدفع الأونلاين
- استلام مباشر بدون مسح باركود

### 🏢 إدارة المخازن
- إنشاء وإدارة مخازن الفرز
- ربط أمناء الفرز بالمخازن
- تتبع الطلبات النشطة في كل مخزن

### 🛣️ المسارات
- 22 منطقة تغطية جاهزة
- إمكانية إنشاء مسارات مخصصة
- توزيع المندوبين على المسارات
- تحديد قيمة التوصيل لكل منطقة

### 👥 إدارة الفريق
- 6 أدوار مختلفة (مالك، موارد بشرية، مشرف عمليات، أمين فرز، محاسب، مندوب)
- صلاحيات مخصصة لكل دور
- تفعيل/تعطيل الحسابات
- ربط الموظفين بالمخازن والمسارات

### 📱 تطبيق المندوب
- واجهة مخصصة للمندوبين
- تسجيل الدخول والخروج من الخدمة
- استلام الشحنات بضغطة زر مباشرة
- تحديث حالة التسليم (في الطريق، وصل، تم التسليم، فشل)
- التقاط صورة إثبات التسليم
- محادثة مباشرة مع الإدارة
- خريطة مباشرة للموقع مع GPS حقيقي
- تحديث الموقع تلقائياً كل 30 ثانية

### 💰 التحصيل النقدي (COD)
- تتبع المبالغ المعلقة لدى المندوبين
- إنشاء تسويات مالية وحفظها في قاعدة البيانات
- إضافة بدلات وجزاءات
- اعتماد التسويات تلقائياً عند الإنشاء
- صلاحيات مقيدة (محاسب COD أو المالك فقط)

### 🚨 إدارة البلاغات
- تسجيل البلاغات والمشاكل
- محادثة مباشرة بين المندوب والإدارة
- قرارات إدارية (إعادة توصيل، رد مبلغ)
- تصنيف حسب الأولوية والنوع

### 📈 التقارير
- تحليلات لحظية
- أسباب فشل التسليم
- تحصيل COD لكل مندوب
- تصدير التقارير بصيغة Excel

## 🔄 آخر التحديثات

### ✅ حذف نظام مسح الباركود
- تم استبدال نظام مسح الباركود بزر استلام مباشر
- المندوب يضغط "استلام الشحنة" مباشرة بدون الحاجة للكاميرا
- نافذة تأكيد بسيطة مع تفاصيل الشحنة

### ✅ تقييد التسوية المالية
- التسوية لا تتم تلقائياً
- فقط محاسب COD أو المالك يمكنهم إنشاء التسويات
- التسوية تُحفظ في قاعدة البيانات فور الإنشاء
- اعتماد تلقائي عند الإنشاء

### ✅ نظام تحديد الموقع المتقدم
- طلب إذن الموقع تلقائياً عند فتح التطبيق
- تحديث الموقع المستمر كل 30 ثانية
- استخدام GPS حقيقي بدلاً من المواقع الوهمية
- حفظ الموقع في قاعدة البيانات
- عرض حالة الموقع في الواجهة

### ✅ نافذة تأكيد الاستلام للجوال
- تصميم مصمم خصيصاً للجوال
- شاشة كاملة بأزرار كبيرة
- ألوان واضحة ومباشرة
- تجربة مستخدم محسنة

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - للكتابة الآمنة
- **Vite** - أداة البناء السريعة
- **Tailwind CSS 4** - للتنسيق
- **Recharts** - للرسوم البيانية
- **Lucide React** - للأيقونات

### Backend & Database
- **Supabase** - قاعدة بيانات PostgreSQL سحابية
- **Realtime** - مزامنة لحظية بين الأجهزة
- **LocalStorage** - للعمل بدون اتصال

### ميزات إضافية
- **PWA** - تطبيق ويب تقدمي (يعمل كتطبيق سطح مكتب)
- **Geolocation API** - تحديد الموقع الحقيقي
- **Service Worker** - العمل دون اتصال
- **Responsive Design** - متوافق مع جميع الأجهزة

## 🗺️ مناطق التغطية

### القليوبية (11 منطقة)
بنها، كفر شكر، طوخ، قها، قليوب، شبين القناطر، الخانكة، العبور، شبرا الخيمة، بهتيم، الخصوص

### القاهرة (11 منطقة)
مسطرد، المرج، السلام، عين شمس، المطرية، النزهة، مصر الجديدة، الزيتون، حدائق القبة، الأميرية، مدينة نصر

## 📊 مراحل الشحنة

1. **تم الإنشاء** - الطلب جديد
2. **مُسند لمندوب** - تم تحديد المندوب
3. **مُسلَّم للمندوب** - المندوب استلم الشحنة
4. **في الطريق** - المندوب في طريقه للعميل
5. **وصل للعميل** - المندوب وصل لموقع العميل
6. **تم التسليم** ✅ - نجاح التسليم
7. **فشل التسليم** ❌ - تعذر التسليم
8. **مرتجع** - تم إرجاع الشحنة

## 📝 ملاحظات مهمة

- النظام يعمل بوضع محلي افتراضياً (البيانات تُحفظ في المتصفح)
- لمزامنة البيانات بين الأجهزة، يجب إعداد Supabase
- الكاميرا تتطلب HTTPS للعمل (لالتقاط صورة الإثبات)
- تحديد الموقع يتطلب HTTPS للعمل
- النظام مصمم للعمل في مصر (أرقام هواتف مصرية، مناطق مصرية)

## 🔧 حل المشاكل الشائعة

### خطأ 410 Gone
- الرابط القديم انتهى صلاحيته
- اعمل build جديد من الواجهة

### الكاميرا لا تعمل
- تأكد من استخدام HTTPS
- اسمح بالكاميرا من إعدادات المتصفح

### الموقع لا يعمل
- تأكد من استخدام HTTPS
- اسمح بتحديد الموقع من إعدادات المتصفح
- تأكد من أن GPS مفعّل في الجهاز
